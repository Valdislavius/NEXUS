## Формулировки и ограничения

- Динамические показатели обновляются с интервалом 2, 5 или 10 секунд. SMART и тома обновляются раз в 30 секунд. История показаний пока не сохраняется.
- CPU: общая и попоточная загрузка, сообщаемая Windows общая частота, характеристики. Не заявлять точную эффективную частоту каждого потока: она была удалена как недостоверная.
- Intel CPU Package: зависит от CPU, установленного PawnIO, корректного ответа датчика и прав. Физическое подтверждение есть для одной проверенной Intel-системы; точная модель исключена из публичной копии. Другие Intel имеют условную совместимость; несколько физических CPU и более 64 логических CPU пока не поддерживаются этим температурным адаптером.
- AMD: общая информация и загрузка доступны, температура AMD пока не реализована. Не формулировать это как полное отсутствие поддержки AMD CPU.
- NVIDIA GPU: датчики через NVML при поддержке драйвером. Не обещать универсальные датчики Intel/AMD GPU или всех видеокарт.
- SATA: RAW, Current/Worst и доступные Threshold представлены отдельно. Неизвестные модели показывают RAW без вымышленного процента здоровья. Проверенный физический SATA-SSD прочитан через Windows Storage; Crucial/Kingston/WD профили проверены на fixtures, native elevated ATA физически не подтверждён.
- USB/RAID/SCSI passthrough не заявлен. SMART не гарантирует исправность диска или сохранность данных.
- NVMe: SMART/Health, температура, доступные показатели; использованный ресурс не является универсальным процентом здоровья.
- Неполученные/устаревшие показатели отображаются как «Нет данных», а не ноль или старое число.
- Локальный экспорт диагностики выполняется по действию пользователя. Нет автоматической отправки. Отчёт исключает серийные номера, имя компьютера/пользователя, IP/MAC, модели/OEM-спецификации и произвольные тексты ошибок.
- Installer: установка для текущего пользователя; включает Collector и официальный офлайн-установщик Microsoft WebView2. Portable: распаковать целиком, оставить Collector рядом, требуется установленный WebView2.
- При запуске 0.3.1 приложение и Collector получают права администратора через штатный UAC. При отказе запуск прекращается. Повышение всего приложения — временное решение Alpha.
- PawnIO устанавливает пользователь отдельно с https://pawnio.eu; NEXUS его автоматически не устанавливает.
- EXE не имеет подписи сертификатом издателя. SmartScreen может предупредить о неизвестном издателе. Предлагать сверить источник и SHA-256; не советовать отключать Defender, SmartScreen или UAC.
- Перед обновлением или удалением закрыть приложение. В первоначальном каталоге тест удаления оставил файлы старой 0.3.0; удаление в новом каталоге прошло полностью.
- Чистая Windows без WebView2, физическая отмена UAC и полный диапазон DPI/длительная нагрузка не были проверены для приложения.

## Скриншоты

Исторические Alpha-снимки реального ПК исключены из публикуемого дерева сайта. Оригиналы сохраняются только локально. Новые изображения Desktop 1.0 должны пройти отдельную визуальную и содержательную проверку и получить точную подпись версии. До этого показывается текстовый статус подготовки снимков.

## Проверка SHA-256

```powershell
Get-FileHash -LiteralPath "$HOME\Downloads\NEXUS-Setup.exe" -Algorithm SHA256
```

Сравнить весь Hash с опубликованной SHA-256 соответствующего файла. Portable проверять до распаковки тем же способом по его полному имени.
