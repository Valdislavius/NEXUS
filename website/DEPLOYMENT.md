# Локальная сборка и будущая публикация

Сайт независим от NEXUS Desktop: статические HTML/CSS/JS и изображения, без доступа
к Collector, локальной SQLite, WebView или API приложения. Для просмотра не нужны
учётная запись, внешняя база данных и работающий NEXUS.exe.

```powershell
npm ci
npm run typecheck
npm run test
npm run build
npm run start -- --port 3001
```

Готовый результат — `out/`, адрес просмотра `http://127.0.0.1:3001`.
Скрипт сборки закрепляет Webpack, поддерживаемый Next.js: это устраняет наблюдавшийся на Windows сбой запуска дочернего PostCSS-процесса Turbopack.
`npm run test:e2e` запускает отдельный сервер на порту 3001 самостоятельно;
перед этой командой закройте ручной сервер или укажите `E2E_BASE_URL`.

Существующие Dockerfile, compose.yaml и docker/nginx.conf сохраняют самостоятельную
конфигурацию будущего размещения. Compose публикует локальный порт 3000 по умолчанию.
Docker-сборка этой ревизии проверяется отдельно: успешный Next.js export не означает
автоматически успешный прогон контейнера.

При будущем размещении на реальном домене задайте `SITE_URL` как origin во время
сборки. Он не должен содержать путь, токены или пароль. Без значения сайт сохраняет
локальную конфигурацию и не выдумывает canonical-домен.

## Каналы продукта

- `src/config/release.ts` хранит публичную Alpha 0.3.1, проверенные ссылки, размеры,
  SHA-256 и неизменённую историю релизов.
- `src/config/desktop.ts` отдельно описывает разрабатываемую Desktop 1.0.0-beta.1.
  В нём нет загрузок, вымышленных хешей и объявления публичного релиза 1.0.
- `src/content/docs.ts` сохраняет прежние 14 статей/якорей Alpha.
  `src/content/desktop-docs.ts` добавляет 5 отдельных статей Desktop 1.0.
- Снимки реального ПК исключены из публикуемого дерева. Новые изображения
  добавляются только после проверки рабочей сборки Desktop, удаления личных
  сведений и указания точной версии; до этого виден текстовый статус.
- Ресурсные бюджеты описаны как цели. Измерение одного Collector не считается
  измерением всего приложения или доказательством отсутствия потери FPS.

Публикация production требует отдельного разрешения владельца. В рамках этой
работы сайт собирается и проверяется локально; автоматическое размещение не настроено.
