# Локальное обновление сайта для Desktop 1.0

Дата: 14 октября 2026 года. Production не публиковался.

## Содержание

- Главная: локальный центр мониторинга/диагностики, раздельные статусы Alpha 0.3.1
  и Desktop 1.0.0-beta.1, направления новой версии и блок производительности.
- Возможности: сохранён текущий каталог Alpha и добавлен отдельно подписанный
  раздел разработки Desktop 1.0.
- Загрузки: проверенные ссылки, размеры и SHA-256 Alpha 0.3.1 сохранены. Нет
  вымышленных новых файлов релиза 1.0.
- Roadmap: шесть этапов новой версии, ограничения и неизменённая история релизов.
- Документация: сохранены 14 статей Alpha/якорей и добавлены пять самостоятельных
  статей Desktop: история, тесты/экспорт, трей/оверлей, ресурсы, совместимость.
- Конфигурация: сайт по-прежнему статический и не требует запущенного Desktop.
  Существующая Docker/Nginx-конфигурация сохранена. Будущая публикация описана
  в DEPLOYMENT.md.

Снимки реального ПК исключены из публикуемого дерева. Главная и раздел
интерфейса показывают текстовый статус: снимки Desktop 1.0 будут добавлены после
проверки интерфейса и удаления личных сведений. Макеты не выдаются за приложение.
Ресурсные ориентиры CPU/RAM/FPS описаны как требующие отдельной проверки.

`test-results/results.json`. Это новые локальные прогоны. Docker-сборка новой
ревизии и production-размещение в эти результаты не входят. Проверка сайта
не является проверкой всех возможностей самого Windows-приложения.

## Приватность публикуемой ветки

Исторические файлы overview.webp, cpu.webp и storage.webp исключены из дерева
сайта после побайтного резервного копирования. Тесты проверяют отсутствие
изображений в DOM и ответ 404 для прежних адресов. Из текстов удалены конкретные
модели проверенного ПК и личный путь рабочей копии. В сохранённом ответе GitHub
API явно отмечено редактирование названий локального оборудования в body;
метаданные релизных файлов, URL, размеры и контрольные суммы не изменены.
