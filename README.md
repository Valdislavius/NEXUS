# NEXUS Desktop

Мониторинг оборудования для Windows x64: CPU, GPU, RAM, накопители, плата, система и сеть.

## Скачать

- **[Alpha 0.3.0 — актуальная версия](https://github.com/Valdislavius/NEXUS/releases/tag/v0.3.0)**
- [Alpha 0.2.0](https://github.com/Valdislavius/NEXUS/releases/tag/v0.2.0)
- [Alpha 0.1.0](https://github.com/Valdislavius/NEXUS/releases/tag/v0.1.0)

В каждом релизе есть установщик, переносимый ZIP и файл SHA-256. Для обычной установки версии 0.3 скачайте **NEXUS-Setup.exe** из Assets. Он включает офлайн-установщик WebView2 Runtime. Для старых версий и переносимого комплекта WebView2 должен быть установлен отдельно.

## Статус

Все версии — предварительные альфа-сборки. Доступность датчиков зависит от оборудования и драйверов. В версии 0.3 интеграция температуры CPU рассчитана на один физический Intel CPU с установленным PawnIO; могут требоваться права администратора. При отсутствии доступа отображается «Нет данных». Проверка температуры сравнением с эталоном и проверка на чистой Windows ещё не завершены.

Этот репозиторий служит архивом готовых релизов. Полный исходный код приложения пока не опубликован; автоматически создаваемые GitHub архивы **Source code** содержат только файлы репозитория. Лицензии и соответствующие материалы сторонних компонентов находятся в дистрибутивах.
