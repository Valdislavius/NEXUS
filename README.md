# NEXUS Monitor Desktop 1.0 beta

Локальный центр мониторинга, истории и диагностики ПК для Windows 10/11 x64.
Tauri 2 · React/TypeScript · Rust · Go Collector · Windows SQLite.

**Разрабатываемая версия: 1.0.0-beta.1. Публичная версия: Alpha 0.3.1.**
Beta сохраняется до аппаратных, игровых и эксплуатационных проверок.
Опубликованные Alpha-релизы и контрольные суммы сохранены.

## Возможности

- Десять страниц: обзор, CPU, GPU, RAM, накопители, плата, сеть, диагностика/тесты, отчёты, настройки. Выбор отдельных устройств и объяснение недоступных датчиков.
- Графики: Live, период, масштаб, перемещение, несколько метрик, отдельные единицы, наведение, min/max/avg, сравнение периодов, события и экспорт агрегированных точек. Поиск и страницы списка позволяют выбрать любой полученный датчик; пропуски не соединяются линией.
- SQLite-история, пакетная запись, минутная агрегация, настраиваемый срок хранения, Timeline и диагностические правила по уже собранным данным.
- Ручные ограниченные CPU/RAM-проверки, чтение файла без записи, сетевые проверки и проверка доступных сведений платы. Прогресс, отмена, температурные ограничения и история результатов.
- CSV, потоковый Excel с листами компонентов, событиями, результатами и агрегатами, PDF-сводка. Для каждого формата выбираются компоненты, период и разделы: сводка, история, диагностика, результаты тестов. Обезличивание включено по умолчанию.
- Нативный трей, необязательный автозапуск, горячие клавиши, Mini/Advanced GDI overlay. Закрытие окна в фоновом режиме уничтожает WebView, сохраняя мониторинг.
- Профили Collector: экономный 5/60 с, сбалансированный 2/30 с, детальный 2/10 с (быстрые/медленные показания). Статический инвентарь кешируется.
- Самостоятельный сайт `website/`: текущая Alpha, разработка 1.0, совместимость, документация, проверяемые загрузки и история релизов.

## Запуск собранной версии

Артефакты создаются отдельно от Alpha в `release/1.0.0-beta.1/`:

- `installer/NEXUS-Setup.exe` — установка для текущего пользователя с официальным офлайн-установщиком WebView2.
- `portable/NEXUS.exe` — после полной распаковки Portable ZIP. Collector и лицензии должны оставаться рядом; нужен установленный WebView2 Runtime.
- `SHA256-1.0.0-beta.1.txt` — суммы конкретных собранных файлов.

Приложение работает с обычными правами. Недоступный привилегированный источник показывает причину. Для совместимого Intel/PawnIO пользователь может сам выполнить повышенный запуск. Изолированный привилегированный broker в beta ещё не поставляется.

Настройки задают поведение закрытия и необязательный автозапуск `--background`. Двойной клик по трею или **Ctrl+Shift+F9** открывает окно; **Ctrl+Shift+F10** переключает оверлей. Сочетания настраиваются, конфликты сообщаются. Полное завершение — «Завершить NEXUS» в меню трея.

## Сборка из исходников

Нужны Node.js 24, Go (версия из `collector/go.mod`), Rust MSVC и Visual Studio C++ Build Tools с Windows SDK.

```powershell
npm ci
npm run desktop:dev
```

Полная сборка с тестами, NSIS и Portable:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

Скрипт подхватывает локальные `.tools/cargo` и `.tools/rustup`, если они имеются. Первая сборка может скачать зависимости и официальный WebView2.

Сайт собирается отдельно:

```powershell
cd website
npm ci
npm test
npm run build
npm start
```

Адрес: `http://127.0.0.1:3000`. Статический результат — `website/out/`. Docker и конфигурация будущего развёртывания: `website/DEPLOYMENT.md`. Production сборочной командой не публикуется.

## Проверки

```powershell
npm test
npm run build
go -C collector test ./...
go -C collector vet ./...
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

Нативная проверка SQLite и отчётов без аппаратной нагрузки:

```powershell
src-tauri\target\release\nexus-desktop.exe --self-check "$pwd\artifacts\native-self-check"
python scripts/verify-reports.py artifacts/native-self-check
```

Это явно синтетические данные. Для независимого чтения файлов нужны Python `openpyxl` и `pypdf`. Проверяются полный отчёт и 12 отдельных экспортов четырёх разделов во всех форматах. Измеритель `scripts/measure-resources.ps1` требует PowerShell 7 и учитывает дерево процессов. Свежий протокол: [23 октября 2026](docs/VALIDATION-2026-10-23.md). Исторические измерения и проверки 14 октября: [VALIDATION-1.0.md](docs/VALIDATION-1.0.md). Они относятся к прежнему бинарному файлу.

## Совместимость и ограничения

Intel Package использует отдельно установленный PawnIO и подписанный IntelMSR. TjMax читается из реального регистра; ACPI не подменяет Package. Прежняя политика MSR сохранена. AMD SMN с записью selector-регистра не используется; безопасного совместимого провайдера температуры AMD в этой версии нет.

GPU-метрики предоставляет установленный NVIDIA NVML. Другие GPU, hotspot, напряжения, вентиляторы, PCIe и лимиты показываются только при реальной поддержке источником. GPU/VRAM benchmark пока не реализован. SMART зависит от контроллера и доступа; неизвестным SATA-моделям не назначается вымышленный процент здоровья.

Оверлей поддерживает обычные и безрамочные окна, если Windows допускает их перекрытие. Эксклюзивный fullscreen и защищённые поверхности не гарантируются. Инъекций, обходов античита и надёжного источника FPS нет. PDF — английская сводка: история ограничена 1000 строками, Timeline — 100 событиями; длинные подписи сокращаются. Полный текст и подробные таблицы доступны в CSV/XLSX. CSV содержит тип строки `record_type` для различения выбранных разделов. RAM-проверка охватывает собственные 64 МиБ; чтение файла зависит от кеша Windows и не проверяет поверхность физического диска.

Данные остаются локально. База, настройки, отчёты, токены и генерируемые файлы исключены из Git. Драйверы скрытно не устанавливаются.

Лицензии: `docs/LICENSES.md`, `docs/THIRD-PARTY-NOTICES.txt`, `docs/PawnIO/`, `docs/MPL-SOURCES/`. Исторические CPU/SATA-ограничения Alpha сохранены в `docs/CPU-COMPATIBILITY-0.3.1.md` и `docs/SATA-SMART-0.3.1.md`.
