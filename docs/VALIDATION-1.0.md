# Проверки Desktop 1.0 beta

Дата: 14 октября 2026. Проверки исходников и файлов выполнены на Windows x64.
Эта запись различает автоматические тесты, реальные аппаратные показания и
эксплуатационные сценарии, которые ещё требуют проверки. Beta не считается
принятым стабильным Desktop 1.0.

## Приватность новой публикации исходников

Исторические отчёты Alpha импортируются в обезличенном виде: индивидуальные
модели и показания тестового компьютера удалены, справочники и искусственные
тестовые данные сохранены. Политика публикации требует подстановки обезличенных
документов во все новые удалённые деревья Git, включая промежуточные импортные
коммиты. Публичная история main, релиз Alpha и его опубликованные архивы
не изменяются. Необезличенные оригиналы и исходные локальные коммиты сохраняются
в локальных резервных копиях и не включаются в новое публикуемое дерево.

Исторические скриншоты с моделями и именем компьютера исключаются из нового
импорта; сайт получает текстовые пояснения вместо этих изображений. Реальных
скриншотов Desktop 1.0 пока нет, поскольку GUI-проверка была остановлена
пользователем клавишей Escape. Текст и макеты не считаются подтверждением
запуска GUI. Эта правка приватности касается документов и сайта; проверенный
бинарный файл Desktop beta и результаты его измерения остаются прежними.

## Измерения ресурсов

CPU нормирован на все 16 логических процессоров. Каждый прогон: 10 секунд
прогрева, затем 60 секунд измерения. Working set суммируется по процессам и
может повторно учитывать общие страницы. Малые значения CPU шумны и не
доказывают пропорциональное ускорение.

| Режим | Средний CPU | Средний working set | Максимум working set | Процессов |
| --- | ---: | ---: | ---: | ---: |
| Alpha 0.3.1, только Collector | 0,0243% | 45,41 МиБ | 46,06 МиБ | 1 |
| Desktop beta, только Collector, balanced | 0,0080% | 45,01 МиБ | 45,71 МиБ | 1 |
| Установленная Alpha 0.3.1, открытое окно | 0,1302% | 464,96 МиБ | 468,27 МиБ | 9 |
| Финальный Desktop beta, `--background`, balanced | 0,0129214% | 70,6016 МиБ | 72,117 МиБ | 3 |

Сырые измерения: `artifacts/baseline/collector-alpha-0.3.1.json`,
`artifacts/collector-desktop1-balanced.json`,
`artifacts/baseline/full-alpha-0.3.1.json`,
`artifacts/desktop1-tray-balanced.json`.
Открытое окно Alpha и фоновый режим Desktop — разные режимы работы; сравнение
показывает стоимость постоянно активного WebView, а не идентичный UI-сценарий.

Финальный фоновый прогон относится к бинарному файлу с SHA-256
`F6F266BD12A56B3ABEF95C85A700EAF4EDF6AA5DA7254D66319DB8F7BAB1A86C`.
Пиковый CPU составил 0,2699%, средний private memory — 45,2914 МиБ.
В дереве наблюдались Desktop, Collector и скрытый `conhost`; дочерних WebView
не было. Снимок дерева сохранён в
`artifacts/desktop1-tray-process-evidence.json`. После измерения помощник завершил
только принадлежащие ему процессы; отсутствие оставшихся процессов подтверждено.
В этом коротком прогоне бюджет фонового CPU/RAM соблюдён. Это не подтверждает
длительную стабильность, поведение после закрытия открытого окна или FPS в игре.
Поле `readySnapshots=0` в режиме измерения дерева приложения означает, что
помощник не читает stdout Collector, и не является проверкой готовности датчиков.

Физические дисковые операции, непрерывная активность GPU и длительный рост
SQLite отдельно не измерены. Ограничение срока хранения не равно фиксированному
размеру базы: при подробном мониторинге за сутки возможны миллионы сырых строк.
Нужно отдельно проверить диск и время запросов на 24-часовой и 7-дневной истории.

## Нативная проверка окна

Debug-приложение запускалось с обычными правами, Collector стартовал отдельным
процессом. Выявлена проблема devUrl `localhost` при сервере, слушающем только
`127.0.0.1`; конфигурация исправлена. Предыдущая попытка открыла страницу ошибки,
поэтому её снимки и IPC не считаются успешной проверкой Desktop.

Управление окнами было остановлено пользователем клавишей Escape. После этого
ввод в окна не продолжался. Нажатия меню трея, физические горячие клавиши,
визуальное перекрытие игровых окон и реальная перезагрузка не объявляются
проверенными. Нативные команды и компоненты покрыты автоматическими тестами
в пределах, указанных выше.

Успешный запуск `--background` и отсутствие дочерних WebView подтверждены
отдельным измерением процессов. Успешная проверка главного GUI, кликов трея,
горячих клавиш и оверлея из этого результата не следует.

## Ограничения до стабильного 1.0

- Нет подтверждённого игрового A/B-прогона среднего FPS, 1% low и frametime.
  Цель ≤2–3% ухудшения не объявляется достигнутой.
- Нужны реальные проверки автозапуска после перезагрузки, сна/пробуждения,
  горячих клавиш, трея и overlay на нескольких DPI/мониторах.
- Нужны чистая установка/удаление и portable на Windows 10 и 11 без готовой
  среды разработки. Сборка установщика не заменяет такую проверку.
- AMD CPU temperature не реализована из-за отсутствия безопасного доступного
  провайдера. Прямые запрещённые записи регистров не используются.
- Метрики GPU ограничены доступным NVIDIA NVML. GPU/VRAM-тесты, универсальный
  FPS-источник, эксклюзивный fullscreen и инъекции не реализованы.
- Не поставляется отдельный привилегированный hardware broker. Обычный UI
  работает без администратора, часть Intel/SMART-источников может быть недоступна.
- RAM-тест охватывает только выделенные 64 МиБ, не всю физическую память и не
  отдельный latency benchmark. CPU-тест — сравнительный алгоритм с ограничением
  доли времени, без рейтинга относительно других моделей.
- Чтение файла зависит от кеша ОС, не проверяет поверхность диска. Тесты записи
  не реализованы, поэтому пользовательские данные ими не изменяются.
- Сетевые тесты ограничены фиксированными общедоступными конечными узлами.
  Полноценный тест пропускной способности не предоставляется без тестового сервера.
- PDF — английская диагностическая сводка. Подробные локализованные объяснения
  и таблицы находятся в Excel; содержимое отчёта выбирается пока через компоненты,
  период и формат, без отдельного переключателя каждой секции.
- Расширенные правила троттлинга, драйверов, подкачки и корреляции частот требуют
  дополнительных надёжных источников и отдельной валидации. Отсутствие правила
  или датчика не является подтверждением исправности.

## Воспроизведение

Основные команды перечислены в README. Результаты финального синтетического
экспорта находятся в `artifacts/backend-self-check-final/`, сводка —
`artifacts/backend-self-check-final.json`: 360 строк метрик, 3 ряда истории,
максимум 56 точек на ряд, 11 листов Excel, 111 кэшированных точек диаграммы,
3 события диагностики. Независимая проверка ZIP/XML прочитала 20 частей;
контрольные PRIVATE-идентификаторы отсутствуют. Более ранняя независимая проверка
Python сохранена в `artifacts/native-self-check-final/verification.json`.
Это синтетические отчёты, а не успешная GUI-проверка или сертификация оборудования.
Нативные GUI-smoke сценарии
в `tests/native-smoke.mjs` запускаются только вручную против специально
включённого локального WebView debug-порта; этот порт не включается штатной
release-конфигурацией. Проверки не отправляют телеметрию на сервер NEXUS.
