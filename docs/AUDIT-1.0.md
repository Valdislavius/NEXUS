# Аудит перед Desktop 1.0

Дата: 14 октября 2026. Платформа проверки: Windows x64, 16 логических процессоров.

## Исходное состояние

Рабочая копия найдена в локальном каталоге проекта; это Alpha 0.3.1, а не версия
из имени каталога «Nexus Alpha 0.1». До изменений Git был без коммитов и remote.
Ветка `feature/nexus-desktop-1.0` создана от исходного `origin/main`
`da1b39e465499e2a72314a4c4453077863ec56e5`. История публичного репозитория сохранена.

До редактирования создан архив 252 исходных файлов:
`artifacts/backups/NEXUS-Alpha-0.3.1-working-tree-before-desktop-1.0.zip`,
SHA-256 `01C1A62966E232734032D727E5931FFAFBC5ADEBD40BD4B2E3F18A2DC88C7EAB`.
Сгенерированные сборки, зависимости и старые release-файлы остаются на диске.

Опубликованный `NEXUS-Desktop-0.3.1-source.zip` скачан из официального релиза.
Его SHA-256 совпал с GitHub:
`5785E1EDDFDB8623440BEDD9A24C27992E45EA465683F98E8BFB67A85CE7A724`.
153 файла опубликованной Alpha совпали с резервным снимком побайтно.
Ещё один `docs/MPL-SOURCES/cssparser-0.36.0/Cargo.lock` присутствовал локально,
но был исключён вложенным `.gitignore` при создании снимка. Он сохранён в Git явно.
Сайт — самостоятельный Next.js static export в `website/`.

## Обезличивание при импорте исходников

Для новой публикации подготовлены обезличенные версии исторических аппаратных
отчётов. Индивидуальные модели, температуры, SMART-счётчики и другие данные
тестового компьютера удалены; справочники поддерживаемых семейств, искусственные
фикстуры, API и ограничения сохранены. Политика импорта требует использовать
эти версии во **всех новых удалённых деревьях Git**, чтобы старые значения не
попали в промежуточные импортные коммиты. Это отбор содержимого новой ветки,
а не изменение публичной истории main или опубликованного релиза Alpha.

Исходные материалы сохраняются локально в `artifacts/privacy-originals/`
и резервной ветке Git; эти копии не входят в публикуемое дерево. Исторические
скриншоты с моделями и именем компьютера исключаются из нового импорта,
а соответствующие материалы сайта заменяются текстовыми пояснениями.
Реальные снимки Desktop 1.0 пока отсутствуют: GUI-проверка была остановлена
пользователем. Макеты не объявляются снимками работающего приложения.
Обезличивание документов и сайта не меняет проверенный бинарный файл beta.

## Архитектура Alpha

React 19 / TypeScript → Tauri 2 (Rust) → Go Collector через JSON Lines.
Collector уже имел безопасные провайдеры Intel/PawnIO, NVIDIA NVML,
Windows Storage/ATA/NVMe, WMI-инвентарь и сетевые счётчики.
Динамический опрос — 2/5/10 секунд, SMART/тома — 30 секунд.
Истории SQLite в найденных исходниках не было. Диагностический журнал хранил
до 128 записей в памяти. Закрытие окна завершало мониторинг.

## Найденные проблемы и решения

| Наблюдение | Изменение Desktop |
| --- | --- |
| Повышение прав всего release-приложения | `asInvoker`; недоступные привилегированные датчики явно сообщают причину |
| Повторное получение конфигурации сетевых интерфейсов в быстром цикле | Отдельный медленный кеш конфигурации; быстрый цикл читает счётчики |
| Временная отметка кадра могла скрывать возраст кешированного датчика | `status`, `maxAgeMs`, время фактического чтения и очистка просроченного значения |
| Нет постоянной истории и корреляции | Ограниченная SQLite-история, агрегация и запросы только выбранного периода |
| Нет профилей фонового режима | Быстрые и медленные интервалы экономного, сбалансированного и детального профилей |
| Все исходники вне истории Git | Импорт Alpha отдельным коммитом поверх main, затем коммиты модулей |

Политика MSR не расширялась. Записи AMD SMN selector-регистров не добавлялись.
Установка драйверов, изменение ACL и отключение защиты не выполняются.

## Исходные проверки

На сохранённой копии Alpha, отдельно от редактируемого дерева:

- 28 frontend-тестов: пройдены; production Vite build: пройден.
- `go test ./...` и `go vet ./...`: пройдены.
- 5 Rust-тестов: пройдены.
- Ограниченная среда первоначально не позволяла Vite realpath и WMI-доступ;
  повторные проверки с обычным доступом к файлам и Windows прошли.
