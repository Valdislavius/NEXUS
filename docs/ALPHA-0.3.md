# NEXUS Alpha 0.3 — CPU Temperature & Installer

## Реализация

Существующие Tauri 2, React/TypeScript, Go и stdin/stdout IPC сохранены; дизайн не менялся. Windows-адаптер Go напрямую открывает установленный PawnIO, загружает подписанный IntelMSR из официального PawnIO.Modules 0.2.11 и вызывает только `ioctl_read_msr` для двух разрешённых регистров:

- IA32_TEMPERATURE_TARGET (0x1A2): TjMax из самого процессора, без предположения «100 °C».
- IA32_PACKAGE_THERM_STATUS (0x1B1): проверка validity bit 31, расстояние до TjMax из bits 22:16. CPU Package = TjMax − distance.

CPUID проверяет Intel и поддержку package thermal management. На время двух чтений Go закрепляет goroutine за OS thread. Ограничение этой реализации — один физический Intel CPU; несколько сокетов и AMD не интерпретируются как Intel. Недостоверные/неполные ответы и ошибки доступа дают null, а не 0 или прошлое показание. Handle закрывается при ошибке и при завершении адаптера; следующий опрос повторяет открытие.

Температура опрашивается вместе с остальными динамическими показателями, каждые 2/5/10 секунд. В основной карточке CPU она заменила «Ядра / потоки»; количество ядер/потоков осталось в подзаголовке. Отсутствие доступа отображается как «Нет данных», причина — в подсказке. Тип **CPU Package**, источник **Intel MSR через PawnIO**, а не ACPI или материнская плата.

Исследованы официальные [IntelCpu.cs](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/dc51e75bd97b15ce17ded0885e67bad47be0765b/LibreHardwareMonitorLib/Hardware/Cpu/IntelCpu.cs), [PawnIo.cs](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/dc51e75bd97b15ce17ded0885e67bad47be0765b/LibreHardwareMonitorLib/PawnIo/PawnIo.cs) и IntelMsr.cs. Бинарный модуль, его лицензия и исходники закреплены в docs/PawnIO. Код LHM/.NET не добавлен в приложение; скачанный официальный LHM находится только среди тестовых артефактов.

## Права и зависимости

Обычная установка — currentUser, без обязательного администратора. На тестовом процессоре Intel установлен PawnIO 2.2.0, но обычному процессу доступ к его устройству запрещён. Для температуры нужен отдельный пользовательский запуск NEXUS от администратора с подтверждением UAC. NEXUS не устанавливает драйвер, не меняет ACL, службы или настройки оборудования. При отсутствии PawnIO пользователь устанавливает его отдельно с официального сайта, осознанно; остальные показатели работают без него.

Запрос UAC для подготовленной read-only утилиты проверки завершился отменой Windows. До получения разрешения проверка реальной температуры и сравнение с LHM не считаются выполненными. Диагностический запуск без повышения вернул Access is denied; числовые показания на этом этапе не подтверждены.

## Установочный пакет

release/installer/NEXUS-Setup.exe — единый NSIS-пакет. В папке installer нет исходников или диагностических файлов. Переносимая версия хранится в release/portable.

Включены Tauri EXE со встроенным React UI, Go collector со встроенным подписанным IntelMSR, лицензии/соответствующие исходники нового модуля и офлайн-установщик WebView2 Evergreen. NSIS проверяет WebView2 и запускает встроенную установку при отсутствии. Отдельное копирование EXE/DLL не требуется. Установка/запуск не требуют интернета; первая сборка и дальнейшие обновления Evergreen могут его использовать. [Официальный способ распространения WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).

## Проверка установки на рабочем ПК

Первый готовый NEXUS-Setup.exe (219 429 820 байт) установлен для текущего пользователя из одного EXE, без ручного копирования: exit code 0. Установленный nexus-desktop.exe версии 0.3.0 запущен вместе с одним дочерним nexus-collector.exe. В окне 8 компонентов, обновляющиеся показатели, в CPU корректно показано «Нет данных» при отказе PawnIO. Снимок: artifacts/alpha03/installed-no-cpu-access.png.

После обычного закрытия окна установленного приложения его EXE и collector завершились. Штатный uninstall.exe /S завершился с кодом 0; отсутствие обоих EXE, записи HKCU и процессов подтверждено в artifacts/alpha03/uninstall-check.json. Предыдущие портативные 0.2 не затрагивались. Чистая Windows не проверялась; WebView2 на рабочем ПК уже установлен, поэтому ветка установки отсутствующего Runtime проверена по сгенерированному NSIS-скрипту, но не исполнена на чистой ОС. Встроенный WebView2 Standalone Installer имеет действительную подпись Microsoft Corporation.

Для последовательного чтения MSR поток временно закрепляется за одним разрешённым логическим CPU, затем исходная affinity восстанавливается. Системы более чем с 64 логическими CPU в этой реализации получают недоступный датчик. Добавлен тест запрета чтения произвольного MSR.
