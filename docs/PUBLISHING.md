# Публикация рабочей ветки

Рабочая ветка: `feature/nexus-desktop-1.0`. Она продолжает обезличенную историю
существующего [PR #1](https://github.com/Valdislavius/NEXUS/pull/1).
Публичные `main`, теги и архивы Alpha остаются сохранены.

После авторизации Git выполните из корня проекта:

```powershell
git status --short
git push -u origin feature/nexus-desktop-1.0
```

Обычный push обновит тот же Pull Request. Если менеджер учётных данных
запрашивает вход, его выполняет пользователь. При временном сбое соединения
можно повторить передачу по HTTP/1.1:

```powershell
git -c http.version=HTTP/1.1 push origin feature/nexus-desktop-1.0
```

Не используйте force-push. В локальной ветке
`local-backup/nexus-desktop-1.0-20261023` сохранены исходные рабочие коммиты
до обезличенного импорта. Она содержит исторические документы и личные снимки
и предназначена только для локального восстановления. Не отправляйте её
и не используйте `git push --all`.

Перед распространением сверяйте файлы с `SHA256-1.0.0-beta.1.txt` из
`release/1.0.0-beta.1/`. Установка, создание GitHub Release и публикация сайта
не выполняются командой push. Сайт развёртывается отдельно по
`website/DEPLOYMENT.md`; публикация production требует отдельного разрешения.
